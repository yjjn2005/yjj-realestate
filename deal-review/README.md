# 거래의 기준 — 부동산 매매 검토 앱

빌딩, 근린생활시설·상가, 대지·나대지·농지·임야, 공장·창고를 **매수자와 매도자 양쪽에서** 검토하는 한국어 앱입니다. 최초 화면의 물건과 비교사례는 명시적인 가상 예시입니다.

## 기능

- 매도 희망가·매수 희망가·매도 협상 하한·실제 분석 가격을 따로 입력합니다.
- NOI 수익환원가치, 면적 보정 거래비교가치, 10년 DCF를 비교합니다.
- 목표 자기자본 현금수익률과 DSCR을 만족하는 매수 상한을 계산합니다.
- 매수 조건과 매도 조건이 겹치는 경우에만 조건부 협상구간을 표시합니다.
- 5년·10년 임대 현금, 매도 대금, 부대비용, 보증금 반환, 대출 상환과 IRR을 계산합니다.
- 개인 일반·사업용과 비사업용 토지 양도세를 비교합니다. 법인세·특례감면은 자동 확정하지 않습니다.
- 텍스트 PDF/TXT 브로셔의 가격·면적·임대료·보증금을 추출하고 원문 확인 후 반영합니다.
- 인쇄/PDF 저장, 독립 HTML 보고서, 입력 JSON, 현금흐름 CSV를 제공합니다.

## 실행 및 검증

Node.js 22 이상에서 별도 앱 의존성 설치 없이 실행합니다. PDF.js는 포함된 Mozilla 배포본이며 Apache-2.0 라이선스를 `vendor/PDFJS-LICENSE`에 보존했습니다.

```sh
npm test
npm run build
```

`site/`는 GitHub Pages용 정적 앱입니다. `worker/index.js`는 화면과 PDF.js, API 프록시를 모두 포함하는 Cloudflare Worker입니다. `worker/index.js`는 `scripts/prepare.mjs`에서 구성합니다. 소스 수정 후 반드시 다시 빌드하세요.

## 공공 API

서버 비밀 설정에 다음을 등록합니다. 값은 GitHub·클라이언트·브라우저 저장소에 넣지 않습니다.

| 변수 | 용도 | 활성화 조건 |
|---|---|---|
| `MOLIT_API_KEY` | 상업업무용·토지·공장창고 매매 실거래 | 공공데이터포털에서 각각 활용신청 및 승인 |
| `ECOS_API_KEY` | 한국은행 기준금리 최신 응답 | ECOS Open API 이용신청 |

키가 없으면 503과 설명을 반환하며 가상 실거래로 대체하지 않습니다. 토지규제·건축물대장·농지·산지 API와 OCR은 현재 자동 연결 범위에 포함하지 않았습니다. 공식 조회 링크와 물건별 확인 목록을 제공합니다.

## Cloudflare 계정에 직접 배포

1. 이 앱 디렉터리를 Cloudflare Worker 프로젝트 루트로 사용합니다.
2. 빌드 명령 `npm run build`, 배포 명령 `npx wrangler@4 deploy`를 설정합니다.
3. Worker 설정의 Variables and Secrets에 `MOLIT_API_KEY`, `ECOS_API_KEY`를 각각 Secret으로 등록합니다.
4. 자체 계정에서 운영한다면 비공개 문서를 입력하는 이용자만 접근하도록 Cloudflare Access를 적용합니다.
5. `/api/status`에서 설정 여부, 실거래 화면에서 승인된 서비스 응답을 확인합니다. 설정 여부는 인증·실데이터 조회 성공을 의미하지 않습니다.

GitHub Actions 템플릿은 `docs/cloudflare-workflow.yml`에 있습니다. 사용자 소유 Cloudflare 계정 인증은 제공되지 않았으므로 자동 배포 완료라고 표시하지 않습니다. 관리형 Cloudflare 배포본은 별도 실행 주소로 제공됩니다.

## 범위와 계산 한계

현재 버전은 근거가 보이는 의사결정 도구입니다. 실거래 후보의 인근 여부, 지번 일부 비공개, 공유지분, 일괄매매와 자산 안분을 사람이 확인해야 합니다. 협상구간은 당사자의 가격 조건이며 거래 성사 확률이 아닙니다. 수익률은 임대소득세 전, 미래 양도세는 현행 세법 유지 가정입니다. 비사업용 기간검토는 윤년을 단순화한 사전 점검이며 최종 법률·세무 판정을 대체하지 않습니다.

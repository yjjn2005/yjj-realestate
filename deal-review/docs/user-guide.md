# 사용 방법

1. 첫 화면은 가상 예시입니다. ‘새 물건 입력’을 누르고 실제 주소·면적·매도 희망가격을 입력하세요.
2. ‘브로셔 분석’에서 문자 PDF 또는 TXT를 선택하거나 원문을 붙여넣으세요. 추출값을 원문과 대조한 다음 적용합니다. 스캔 이미지 PDF는 OCR한 텍스트를 붙여넣어야 합니다.
3. 실제 임대료, 공실, 운영비, 재산세·보험료, 수선, 보증금, 대출 조건과 초기 공사비를 입력하세요. 현재 수취 임대료를 입력하면 공실을 중복 차감하지 않습니다.
4. 무수익 토지는 ‘실거래 비교’에서 검증한 비교사례를 입력해야 가치평가가 가능합니다. 공공 API 키가 연결되어야 자동 후보 조회를 할 수 있습니다. 수동·CSV 입력은 즉시 사용할 수 있습니다.
5. 매수 희망과 매도 협상 하한을 입력합니다. 목표 현금수익률·DSCR이 매수 상한을 제한합니다. 하한과 상한이 겹칠 때만 협상 가능한 범위가 나타납니다.
6. ‘법률·세금’에서 개인/법인, 취득원가, 필요경비, 보유기간, 현재 대출, 양도 기본공제와 사업용 여부를 확인합니다. 취득원가 미입력·법인 거래는 현재 매도세액을 보류합니다.
7. ‘5년·10년 수익’에서 기준·보수·개선 시나리오를 바꾸어 비교합니다. 선택한 시나리오가 보고서에도 표시됩니다.
8. 상단 ‘보고서·PDF 출력’을 누르고 인쇄 대화상자에서 ‘PDF로 저장’을 선택하세요. ‘보고서 파일 저장’은 독립 HTML 보고서입니다. ‘입력 저장’은 다음 작업에 다시 불러올 JSON입니다.

입력은 페이지를 닫으면 사라집니다. 유지할 물건은 ‘입력 저장’으로 파일을 내려받으세요. 파일과 PDF는 이 기기에서 처리하며 서버에 저장하지 않습니다. 공공 API에는 지역·계약월·유형만 요청합니다.

금액은 만원, 면적은 ㎡입니다. 기본공제와 비용의 확인 여부, 수익률에서 제외된 임대소득세, 법률 미확인 항목은 보고서에 남습니다. 단순 가격 범위만으로 매수·매도를 확정하지 마세요.

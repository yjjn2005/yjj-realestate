# 부동산 매매 검토 앱 기초조사와 구현 방향

조사 기준일: 2026-10-01 / 대상: 대한민국 비주거 부동산과 토지 / 개인 매수·매도 우선, 법인 거래는 추가 세무검토

## 판단을 먼저 분리해야 한다

합리적 **시장가치**, 투자자가 감당할 수 있는 **매수 상한**, 매도자의 **협상 하한**, 실제 **협상구간**은 서로 다르다. 호가나 희망가만으로 시장가치를 계산하면 자기참조가 된다. 현재 버전은 독립적인 임대 순수익 및 비교거래를 가치의 근거로 사용하고, 희망가격은 별도 조건으로 적용한다. 교집합이 없으면 중간값을 거래 성사 가격으로 내놓지 않는다.

공인 감정평가액과 매도자 주장, API 후보, 사용자 가정, 검증한 사실은 서로 다른 성격이다. 최초 물건과 비교거래는 가상 예시로 명시하고 실제 물건으로 전환할 때 비교 예시를 제거한다. 사업용 여부·취득원가·실거래가·법률 문서가 부족하면 해당 판단을 보류한다.

어댑터는 월별 오류와 부분 응답을 표시하고 해제·지분 후보를 제외한다. API는 진실성의 최종 보증이 아니다. 신고 지연·정정·부분 지번·일괄매매·특수관계 거래 가능성을 확인해야 한다. 현재 인증키가 없어 실공공데이터 응답에 대한 전체 통합검증은 아직 수행하지 않았다.

## 2026년 시장 자료를 사용하는 방법

한국은행 2026-08-27 결정의 기준금리는 3.00%로 확인했다. 실제 담보대출은 기준금리와 일치하지 않으며 금융기관 견적의 가산금리·변동주기·LTV·만기·중도상환수수료를 입력해야 한다.

CBRE의 2026년 2분기 서울 3대 업무권역 A급 오피스 평균 공실률은 4.2%이며 수도권 A급 물류센터 전체 공실률은 14.6%다. 물류의 상온 8.7%, 저온 33.0%는 기능별 차이가 크다는 근거다. 이런 표본 지표를 소형 근생상가·농촌 창고·개별 공장에 그대로 적용하지 않는다. 개별 임대차 원장, 주변 경쟁 공급, 실제 임차 수요 확인이 우선이다. 한국부동산원의 공실률은 표본의 공실면적 / 임대가능면적이며 전국 전수조사가 아니다.

농지는 농지공간포털에서 이용실태·진흥지역 등의 정보를 조사하고 관할기관에서 실제 적법 이용·전용 가능성을 확인한다. 단순 지목이나 인근 공장 거래로 농지의 개발 프리미엄을 자동 산출하지 않는다. 임야는 보전 여부·지형·진입로·산지전용 및 복구비가 개발 잔여가치를 바꾼다.

## 계산 규칙

1. 만실 임대료 × (1 − 공실률) = 유효 수취 임대료. 현재 수취액 입력이면 공실을 재차 차감하지 않는다.
2. NOI = 유효 수취 임대료 − 운영비. 대출이자·소득세·수선 적립은 NOI 밖에서 처리한다.
3. 수익환원가치 = NOI / 환원율. 환원율은 대출금리나 단순 총임대수익률과 다르다.
4. 거래비교 = 동일 면적 기준 단가 × 대상 면적 × 보정계수. 건물 포함 총매매가의 토지면적 단가는 순수 토지 단가가 아니다.
5. 두 가치가 존재하면 각 50% 가중한다. 단일 근거는 명시한다. ±평가범위는 사용자 가정이며 통계적 신뢰구간이 아니다.
6. DCF는 10년 NOI에서 연 수선 적립을 차감한 현금과 11년차 NOI / 매도 환원율에 의한 매도 가치를 할인한다. 매도비용을 반영하되 대출·양도세는 자산 가치평가와 분리한다.
7. 초기 자기자본 = 매수가 + 취득세·매수비·공사비·VAT 순부담 − 대출 − 보증금. 보증금은 수익이 아니며 매도 시 동일 금액 반환으로 처리한다.
8. 연 임대 현금 = NOI − 수선 적립 − 대출 원리금. 만기일시상환은 입력 만기에 원금을 상환하며 만기 연장이나 차환을 자동 가정하지 않는다.
9. 마지막 매도 현금 = 미래 매도가 − 매도비용 − 대출잔액 − 보증금 − 선택한 추정 양도세. 임대소득세는 미반영이다.
10. ROI = (누적 임대 현금 + 마지막 매도 현금 − 초기 자기자본) / 초기 자기자본. IRR은 연간 현금열의 할인율을 푼다. 자기자본 0 이하 또는 여러 부호 전환으로 복수 IRR 가능성이 있으면 보류한다.

원리금 균등은 연 단위 모델이며 실제 월별 금융기관 상환표와 차이가 날 수 있다. 개발 잔여법(완공 매각가 − 공사·인허가·금융·판매비용 − 개발 이윤)은 아직 자동 산출하지 않는다. 공사비·허가 가능성이 검증되지 않은 개발가치를 시장가치에 섞지 않기 위한 범위 선택이다.

## 세법과 법률 로직

개인 일반 토지·건물은 과표별 기본세율 6~45%와 누진공제를 사용한다. 일반 장특공은 3년 이상 6%, 매년 2%, 최대 30%다. 비사업용 토지는 기본세율에 10%p를 가산하고 단기보유 세율과 경합하면 큰 산출세액을 적용한다. 개인지방소득세는 해당 국세의 10%로 단순 추정한다. 현재 건물·토지 일괄 양도는 과표에 토지 안분율을 적용하여 추가세를 근사하므로 자산별 실제 차익·원가·공제가 다르면 세무사의 개별 산출이 필요하다.

비사업용 판정에는 실제 사용과 법정 예외, 소유기간별 일수 요건이 모두 필요하다. 5년 이상은 직전 5년 중 2년 초과, 직전 3년 중 1년 초과, 전체 보유기간 40% 초과의 비사업 기간을 모두 충족하는지 본다. 현재 앱의 사전 점검은 365일 연 환산이므로 날짜·윤년의 경계 사례는 최종 판정을 보류한다. 자경농지 감면·상속·법령상 사용 제한 등의 특례를 자동 적용하지 않는다.

법인의 업무무관 자산·비사업용 토지 규정은 개인 양도세와 다르다. 법인세·토지등 양도소득 추가과세·손익통산·지방세·과밀억제권역 중과는 현재 자동 산출 범위 밖이다. 주택 혼합 건물과 지정지역의 추가 중과도 별도 검토한다. 일반 주택 외 취득 합계 4.6%, 신규 농지 3.4%는 공식 안내의 일반 예시이며 실제 감면·중과·과표를 확인하여 입력률을 수정한다.

## 완전 자동화로 확장하는 순서

| 단계 | 확보할 조건 | 완성 기준 |
|---|---|---|
| 1. 실데이터 | 승인된 MOLIT·ECOS 키 | 지역·월별 원응답, 오류·0건·해제/지분, 관측일을 실조회로 검증 |
| 2. 필지 확인 | 주소 정규화·PNU·좌표·용도 API | 대상·비교사례의 식별 일치 및 반경 검색의 근거 보존 |
| 3. 브로셔 보강 | OCR 서비스, 문서별 원문 좌표 | 값·단위·필드·페이지 연결, 신뢰도 낮으면 사용자 확인 |
| 4. 법률·세무 | 적법한 권리문서·계약·증빙·날짜 | 법정 예외·법인·혼합자산·연간 합산을 전문가 검증 후 확장 |
| 5. 개발 분석 | 허가 가능·사업비·완공 매각 근거 | 잔여법을 기존 합법적 이용가치와 별도 시나리오로 표시 |

시장 업종별 수요와 거래 성사 확률 모델은 확정 데이터 없이 숫자를 만들지 않는다. 확률 모델은 실제 매도기간·가격조정·거래종결 데이터와 표본 외 검증을 확보한 다음 단계다.
